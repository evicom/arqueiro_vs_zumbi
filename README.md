# 🏹 Arqueiro vs Zumbis - PWA

Jogo HTML5 instalável como app em qualquer dispositivo.

## 🚀 Publicar no GitHub Pages

1. Crie um repositório no GitHub (ex: `arqueiro-vs-zumbis`)
2. Envie os arquivos:
   ```bash
   git init
   git add .
   git commit -m "Jogo Arqueiro vs Zumbis PWA"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/arqueiro-vs-zumbis.git
   git push -u origin main
